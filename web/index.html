How this works

1. The data

All 98,186 diagnosis codes of the CMS ICD-10-CM 2026 release, merged with the XML tabular list so every code carries its chapter, its block and its official synonyms (“inclusion terms”).

2. Two retrievers

A semantic arm embeds every code description with bge-small-en-v1.5 and compares meanings; a keyword arm runs BM25 over an inverted index. They fail on different queries, which is why both are used.

3. Fusion

The two ranked lists are merged with Reciprocal Rank Fusion, which combines ranks rather than scores — cosine similarity and BM25 are not on a comparable scale.

4. Measured, not asserted

Quality is scored against a gold set built from the CMS Alphabetic Index, so the labels come from CMS rather than from me. See the numbers below.
